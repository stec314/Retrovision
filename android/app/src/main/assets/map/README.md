Offline map style assets (nothing here is fetched at run time).

- `layers-dark.json`: layers from `@protomaps/basemaps` 5.7.2,
  `layers("protomaps", namedFlavor("dark"), {lang: "it"})`, with font names written without spaces
  (they become asset paths).
- `fonts/`: Noto Sans glyph ranges (Latin, Latin extended, Greek, Cyrillic, punctuation) from
  protomaps/basemaps-assets. Labels in other scripts are not drawn.
- `sprites/`: protomaps/basemaps-assets `sprites/v4/dark`.
